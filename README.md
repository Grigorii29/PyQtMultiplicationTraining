# PyQt приложение для тренировки умножения

Приложение написано на PyQt6. Цель приложения - помощь ученникам начально школы трениировать умножение двузначных чисел на однозначное
Для запуска скачайте файл Simulator.exe из папки App
Simulator.exe - готовое к использованию приложение
В верхнем поле укажите количество примеров, которое планируете решить, нажмите кнопку старт. Начнут появлять решения. Вводите ответ в поле, находящееся рядом с примером. Для ответа нажмите Enter. Система проверит правильность решения и выдаст следующий пример
